# 日本通运(NX Holdings, 9147.T) vs. Logisteed(旧·日立物流)—— 业务对比 memo

*Author: buy-side analyst*
*As of 2026-06-16。NX Holdings 财年为 12 月制(2022 年从 3 月制改过来);Logisteed 财年为 3 月制。*
*这是一份"两家公司哪里可比、哪里不可比"的对比 memo,不是单边推荐。*

---

## 📖 五分钟读懂(中文导读,给完全没接触过物流行业的读者)

**先回答你的原问题:这两家公司"可比在哪里"?**

一句话:**它们是日本物流业的"前二大综合物流集团",在 3PL(第三方物流)和国际货代这两块业务上正面重叠、抢同一批客户**——所以放在一起对比是合理的。但它们的"出身"完全不同,这导致资产结构、利润率、所有权都不一样,这才是对比的看点。

**两家公司是干嘛的(各一句话):**
- **日本通运(Nippon Express / NX Holdings,9147.T,东京交易所上市):** 日本最大的综合物流集团,1872 年成立(150 年历史),**出身是"运输承运人"**——卡车、铁路、海运、空运货代起家,全球 49 个国家、约 7.6 万员工,年收入约 **2.57 万亿日元**(约 170 亿美元)。
- **Logisteed(旧名"日立物流",原 9086.T,已退市):** 日本最大的 **3PL / 合同物流**公司之一,**出身是"日立集团的内部物流部门"**(给制造业做仓储、库存管理、工厂物流),后来独立。2022 年被美国私募 **KKR** 收购退市,2023 年改名 Logisteed;年收入约 **8,000 亿日元**,正冲击 1 万亿。

**核心一句话差异(整篇 memo 的 takeaway):**
> **NX 是"运出身"的全球货代巨头(资产重、毛利薄、规模大、上市);Logisteed 是"仓出身"的 3PL 专家(资产相对轻、利润率高、被 PE 控股、正在并购扩张)。** 两者在"帮制造业管供应链"这件事上越来越像、越来越正面竞争,但赚钱方式和资本故事完全不同。

**为什么现在值得对比?**
1. **行业在洗牌:** 日本物流业正在大整合。Logisteed 被 KKR 买走后疯狂并购(吞了 ALPS 物流),2025 年又拉来**日本邮政(Japan Post)入股 19.9%**;NX 这边则靠收欧洲资产(奥地利 cargo-partner、德国 Simon Hegele 医药物流)往全球货代第一梯队挤。
2. **后疫情利润正常化:** 2021-22 年海空运费暴涨,两家都赚翻;2023 年起运价回落,**NX 的营业利润从 ¥1,376 亿(2022)一路掉到 ¥515 亿(2025)**,利润率被打回 2% 出头。这对两家"谁的护城河更硬"是一次真实压力测试。

**文中出现的公司 / 名词:**
- **3PL(Third-Party Logistics,第三方物流):** 企业把仓储、配送、库存管理等物流环节外包给专业公司;
- **货代(Freight Forwarding):** 帮货主订舱、报关、安排海空运,自己不一定有船有飞机,赚的是"组织运输"的钱;
- **合同物流 / 系统物流:** 长期合同,帮客户运营整个物流中心/工厂物流,黏性高;
- **KKR:** 美国大型私募基金(本系列其他 memo 也提过);
- **ALPS LOGISTICS(阿尔卑斯物流):** 电子零部件物流公司,被 Logisteed 并购;
- **cargo-partner / Simon Hegele:** NX 收购的欧洲货代 / 医药物流公司;
- **Japan Post(日本邮政):** 日本邮政集团,旗下有 Toll(澳洲物流)、JP 物流等。

**你应该带走的 3 个 takeaway:**
1. **可比:** 都是日本前二的综合物流集团,在 3PL + 国际货代上正面重叠,客户都是制造业(汽车、电子、医药)。
2. **不可比 / 核心差异:** 出身不同(运 vs 仓)→ 资产结构、利润率不同;所有权不同(NX 上市 vs Logisteed 被 KKR + 日本邮政控股)。
3. **投资视角:** NX 是"可买的低估值周期+重估值股";Logisteed 暂时买不到(私有),但它是观察日本物流整合、以及未来"重新上市(re-IPO)"套利机会的关键标的。

## 一、两家到底"可比在哪"——三个重叠点

| 重叠维度 | 说明 |
|---|---|
| **① 都是日本"综合物流"第一梯队** | 按收入,NX(~¥2.57 万亿)是日本物流业绝对第一;Logisteed(~¥0.8–1.0 万亿)是 3PL 领域第一梯队。两者 + 山九、近铁世界快运(KWE)、Sagawa/Yamato(快递为主)构成日本物流头部。 |
| **② 3PL / 合同物流正面竞争** | 这是最直接的重叠:都给汽车、电子、医药、零售等制造业客户运营物流中心、做库存与供应链管理。Logisteed 是这块的"原生玩家",NX 是从货代往这块延伸。 |
| **③ 国际货代 + 海外扩张靠并购** | 两家都在"买出海":NX 收 cargo-partner(中东欧货代)、Simon Hegele(德国医药);Logisteed 借 KKR 资本做亚洲 3PL roll-up。都想成为"亚洲乃至全球 3PL 头部"。 |

**结论:** 客户群、服务清单、扩张打法高度重叠 → 放一起对比合理。下面看它们的"不一样",这才是关键。

---

## 二、核心差异:出身决定一切

### 1. DNA:承运人 vs 货主物流部
- **NX(承运人出身):** 1872 年作为运输公司起家,核心能力是**自己组织运力**——铁路、卡车、海运、空运货代,还有日本独有的**现金护运(Security Transportation)**和**重大件运输/建设(Heavy Haulage & Construction)**业务。资产偏重(车队、网点、海空运代理网络)。
- **Logisteed(货主物流部出身):** 前身是**日立集团的内部物流部门**,基因是"帮一家大制造业管好整条供应链"。强在**合同物流/系统物流**——运营客户的物流中心、工厂线边物流,IT 系统(WMS/数字化)嵌得深,客户黏性高,资产相对轻(很多是"运营"而非"持有")。

> 一个形象比喻:**NX 像"搬运 + 跨境运输的全能选手";Logisteed 像"帮工厂当物流大脑的外包 CTO"。**

### 2. 规模 vs 利润率(数据对比)

| 指标 | **NX Holdings(9147.T)** | **Logisteed(旧日立物流)** |
|---|---|---|
| 最新年收入 | **¥2.57 万亿**(FY2025,12 月制) | **~¥0.8 万亿**,FY2025 目标冲 **¥1 万亿**(含 ALPS 并表) |
| 营业利润(最新) | **¥515 亿**(FY2025) | 历史 OP 率约 **5%**(私有后不再公开披露,口径约 ¥400–500 亿级) |
| 营业利润率 | **~2.0%**(FY2025);疫情高峰 FY2022 曾 5.3% | **~5%**(历史区间,结构性高于 NX) |
| 员工 | 约 **76,389** 人 | 约 4–5 万人(含并购后,口径不一) |
| 海外覆盖 | **49 个国家 / ~735 网点** | 约 **28 个国家** |
| 成立 / 历史 | 1872(150 年) | 1950 年(日立系) |
| 上市状态 | **东证 Prime 上市** | **2022 年被 KKR 私有化退市** |

**读这张表的关键:**
- **规模 NX 大 3 倍**(¥2.57 万亿 vs ~¥0.8 万亿),但**利润率 Logisteed 高一倍多**(~5% vs ~2%)。
- 原因正是"运 vs 仓":**货代/运输是薄毛利、量大、对运价周期敏感**的生意;**合同物流是高黏性、签长约、利润率更稳**的生意。这解释了为什么 KKR 看上的是 Logisteed(高质量现金流、可加杠杆、可整合)。

### 3. NX 的利润为什么在掉?(后疫情正常化的活教材)

NX 营业利润轨迹(FY,12 月制):

| 财年 | 收入(¥亿) | 营业利润(¥亿) | OP 率 |
|---|---|---|---|
| FY2021 | 23,510 | 917 | 3.9% |
| FY2022 | 26,187 | **1,376** | **5.3%**(海空运费暴涨高峰) |
| FY2023 | 22,390 | 813 | 3.6% |
| FY2024 | 25,776 | 636 | 2.5% |
| FY2025 | 25,748 | **515** | **2.0%** |

- FY2022 是**海空运费泡沫**的顶点,货代赚翻;之后运价回落,叠加日本国内人工成本上升、海外并购摊销,**利润被持续挤压**。FY2025 净利润更是只有 ¥27 亿(被税和一次性项目吃掉),是个低点。
- 这正好暴露了 **NX 的脆弱性:利润率薄、对运价周期高度敏感**。Logisteed 的合同物流模式理论上更抗周期——这是它"可比但更优质"的核心论点。

### 4. 所有权与资本故事(最大的不可比项)

- **NX:** 公开上市,市值约 **¥1.22 万亿(~80 亿美元)**,股价 ¥5,032,β 仅 0.59(防御型),股息 ¥100。**散户/机构都能买**。故事是"低估值 + 利润触底回升 + 重估值(P/B 修复)"。
- **Logisteed:** **买不到**。2022 年 KKR 以约 ¥8,913/股要约收购、私有化退市,日立保留 10%。2025 年 10 月**日本邮政斥资 ¥1,422 亿(~9.49 亿美元)收购 19.9% 股权**(隐含整体股权估值约 ¥7,000 亿+)。
  - 这意味着:Logisteed 现在是 **KKR(控股)+ 日立(10%)+ 日本邮政(19.9%)** 的组合,KKR 大概率在养肥后**重新 IPO 或转售**——这是未来 1–3 年日本物流最值得盯的资本事件之一。

## 三、业务结构并排(谁强在哪)

| 业务线 | NX Holdings | Logisteed |
|---|---|---|
| **国际货代(空/海运)** | ⭐⭐⭐ 核心强项,全球网络 | ⭐⭐ 在补,借并购扩张 |
| **国内 3PL / 合同物流** | ⭐⭐ 在延伸 | ⭐⭐⭐ **原生强项**,系统物流/数字化深 |
| **重大件/工程物流** | ⭐⭐⭐ 独有强项(发电设备、大型机械) | ⭐ 弱 |
| **现金/贵重品护运** | ⭐⭐⭐ 日本独有牌照业务 | — 无 |
| **电子零部件物流** | ⭐ | ⭐⭐⭐ 并购 ALPS LOGISTICS 后大幅加强 |
| **医药/冷链物流** | ⭐⭐⭐ 收购 Simon Hegele(德国医药) | ⭐⭐ 在做 |
| **最后一公里/快递** | ⭐ 弱 | ⭐⭐ 借**日本邮政**网络补强(战略联盟核心) |

**一句话:** NX 强在"运得到、运得了大件/特殊货"(货代 + 重大件 + 护运);Logisteed 强在"帮你管好整条链 + 电子件 + 现在接上日本邮政的最后一公里"。两者在 3PL 中段重叠,但两端各有护城河。

## 四、投资视角小结(给 IC 的话)

1. **如果只能买一个 / 想买:只有 NX 能买。** 它是日本物流防御型蓝筹,β 0.59,股息稳定,当前估值不贵(净利触底)。逻辑是"运价周期触底 + 海外并购整合见效 + 利润率从 2% 往 3–4% 修复"。**风险:** 货代生意薄毛利、对运价/汇率/日本人工成本高度敏感,利润率修复能否兑现是关键。
2. **Logisteed 是"更优质但买不到"的那个。** 商业模式(高黏性合同物流、~5% OP 率)结构性优于 NX,但已被 PE 私有化。**真正的机会是事件驱动:** 盯 KKR 的退出路径——若**重新 IPO**,会是日本物流近年最大的新股之一,届时可对标 NX、山九、欧洲 GXO/DSV 来定价。
3. **行业层面的 takeaway:** 日本物流正从"分散、低利润、内需为主"走向"PE 主导的整合 + 出海并购"。Logisteed(KKR)、Japan Post(Toll + Logisteed 19.9%)、NX(欧洲并购)是三条主线。**谁能把合同物流的高利润率 + 货代的全球网络 + 最后一公里捏在一起,谁就是赢家**——目前没人全占,这是后续跟踪的核心问题。

## 五、数据质量与口径说明(必须先看)

- **NX 数据**来自 FMP(9147.T,12 月制财年)与公司 IR;**FY2025 收入 ¥2.57 万亿、营业利润 ¥515 亿为已披露口径**。注意公司早先指引曾给到收入 ¥2.7 万亿,实际落在 ¥2.57 万亿,且利润弱于指引——指引与实际有差,memo 采用 FMP 实际数。
- **Logisteed 私有化后财务披露大幅减少**,本文 ~¥0.8 万亿收入、~5% OP 率、28 国等为**退市前后公开资料 + 第三方(Transport Intelligence 等)估算**,精度低于 NX,**不应按精确数使用**。FY2025 "冲 1 万亿"为含 ALPS 并表的目标口径。
- **日本邮政入股**:¥1,422 亿买 19.9%(2025-10 公告),隐含股权估值为按比例反推,非官方披露的企业价值。
- 两家**财年口径不同**(NX 12 月制 / Logisteed 3 月制),跨年比较时请注意错位约一季度。
- 本 memo 为业务对比,**非买入/卖出建议**;NX 的多空两面都已列出,Logisteed 因不可交易仅作事件跟踪。
