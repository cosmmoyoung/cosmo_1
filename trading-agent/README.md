# 市场监测 Agent —— 从零开始的导师手册

> 写给没有技术背景、但有自己交易思路的你。
> 先花 10 分钟读完这份文档,你会对"这个东西到底是什么"有完整的认知。

---

## 一、先回答你最核心的困惑:成品到底是什么?

**不是 EXE。** 你朋友用 Claude Code 写的 trading signal,成品形态几乎可以肯定是:

```
一段定时自动运行的程序(云端或本地)
        ↓ 每天固定时间
抓数据 → 分析 → 生成信号
        ↓
推送到你手机(Telegram / 邮件)一份"晨报"
```

你每天的体验是:**早上打开手机,收到一份 AI 帮你写好的市场简报**,里面有:
昨天你的股票池谁异动了、你追踪的大佬说了什么、这两者交叉验证出什么线索、
以及"建议关注什么"。你看完做决定,下单还是你自己来(至少前几个月应该如此)。

## 二、系统架构(已经替你搭好了)

```
┌─────────────────────  数据采集层  ─────────────────────┐
│  行情:Yahoo(免费)或 FMP(免费档够用)                  │
│  叙事:RSS 新闻(免费)+ X 大佬发言(可选,$200/月)      │
└──────────────────────────┬───────────────────────────┘
                           ↓
┌─────────────────────  分析层  ────────────────────────┐
│  1. 规则引擎(免费):机械筛异动——大涨大跌、接近新高、    │
│     深度回调、均线位置                                  │
│  2. LLM 分析(Claude):读全部材料,做"叙事 × 价格"      │
│     交叉验证,输出带置信度的关注建议 + 反方视角          │
└──────────────────────────┬───────────────────────────┘
                           ↓
┌─────────────────  输出层  ────────────────────────────┐
│  markdown 晨报 + 信号留痕(signals.jsonl)              │
│  推送:Telegram(免费)/ 邮件                           │
└───────────────────────────────────────────────────────┘
```

对应的代码结构:

```
trading-agent/
├── config.yaml          ← 你的"大脑":投资主题、股票池、追踪人物(改这里,不用懂代码)
├── main.py              ← 入口,串起整条流水线
├── agent/
│   ├── sources/         ← 数据采集:market.py / news.py / x_source.py
│   ├── analysis/        ← signals.py(规则)/ llm.py(Claude 分析)
│   ├── report.py        ← 生成日报 + 信号留痕
│   └── notify.py        ← Telegram / 邮件推送
├── reports/             ← 每天的日报会存在这里
└── data/fixtures/       ← 演示数据(真实行情快照)
```

## 三、怎么跑起来

### 3.1 先看演示(不需要任何 API key)

```bash
cd trading-agent
pip install pyyaml requests
python main.py --demo
```

会用 2026-07-04 的真实行情快照生成一份 `reports/brief-*.md`,让你看到成品长什么样。

### 3.2 真实运行(在你自己电脑上)

```bash
pip install -r requirements.txt
cp .env.example .env     # 用文本编辑器打开 .env,至少填 ANTHROPIC_API_KEY
python main.py
```

### 3.3 正式部署(推荐:GitHub Actions,免费)

仓库里已经放好了 `.github/workflows/daily-brief.yml`。你只需要:

1. 打开仓库页面 → **Settings → Secrets and variables → Actions**
2. 点 **New repository secret**,把 `ANTHROPIC_API_KEY`(以及可选的
   `TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID`)加进去
3. 打开 **Actions** 标签页,选 `daily-market-brief`,点 **Run workflow** 测试一次

之后每个交易日美股收盘后,GitHub 会自动跑一遍,把日报提交回仓库并推送到你的
Telegram。**不需要租服务器,不需要电脑开机。**

## 四、成本明细(你问的"要花多少钱")

| 项目 | 起步阶段 | 说明 |
|---|---|---|
| 部署(GitHub Actions) | **$0** | 公开仓库免费;私有仓库每月 2000 分钟额度,日报一天用 ~2 分钟,绰绰有余 |
| 行情数据(Yahoo/FMP 免费档) | **$0** | 日报级别完全够;要盘中分钟级数据才需要付费 |
| 新闻(RSS) | **$0** | TechCrunch、HackerNews 等 |
| LLM 分析(Claude API) | **$3–15/月** | 每天一次日报,sonnet 模型,量很小 |
| Telegram 推送 | **$0** | |
| **起步合计** | **≈ $5–15/月** | |
| X API(追踪大佬推文) | +$200/月 | 官方 Basic 档,读 1 万条/月。**建议第二阶段再上** |
| VPS 云服务器 | +$5–12/月 | 只有做"盘中实时监控"才需要,日报模式不用 |
| 券商 API(Alpaca 模拟盘) | $0 | 第三阶段:让系统模拟下单验证策略 |

**关于 X API 的导师建议**:$200/月是整个项目最大的开销,先别花。大佬的重要观点
几乎都会在几小时内被科技媒体报道,RSS 免费就能拿到,只是慢几个小时——对日报级
别的系统毫无影响。等你用了两三个月、确认这套流程真的产生价值、且确认"快几小时"
值 $200,再升级。另外注意:抓取(爬虫)X 违反其服务条款,不要走这条路。

## 五、这套系统的"信号哲学"(最重要的一节)

你的思路——"追踪 AI 瓶颈 + 大佬观点变化"——本质上是一个**叙事领先型策略**:
科技圈内部人的判断,领先卖方研报和主流媒体 1–4 周。这个思路是成立的,但有三个
你必须知道的坑:

1. **大佬发言噪音极大**。Elon 一天发 20 条,99% 与投资无关;有些"大佬"发言
   本身就是为了带节奏(他们的仓位和你利益相反)。所以系统设计成:LLM 只提取
   "与你的投资主题相关的观点变化",并且强制输出"反方视角"一节。
2. **信号 ≠ 收益,留痕才能进化**。系统每天把信号写进 `reports/signals.jsonl`。
   三个月后,你可以统计:"深度回调"信号发出后 20 天平均收益是多少?哪类信号
   有效、哪类是噪音?**这是从"我感觉这个信号不错"到"我有数据证明"的唯一路径。**
   你朋友的 signal 如果没有这个环节,大概率是幸存者偏差。
3. **绝对不要一开始就自动下单**。路线图是:
   人肉验证(1–3 个月)→ 模拟盘(Alpaca paper trading,免费)→ 小仓位实盘。
   跳过前两步的人,基本都是给市场交学费。

## 六、进化路线图

- **Phase 0(现在)**:日报 MVP ✅ 已完成——行情 + 新闻 + 规则信号 + LLM 分析 + 留痕
- **Phase 1(第 1–2 周)**:配好 API key 和 Telegram,让它每天真实运行;
  每周微调 `config.yaml` 里的投资主题和股票池
- **Phase 2(第 1–2 个月)**:写一个信号评分脚本,回看 signals.jsonl 里每条信号
  之后 1/5/20 天的实际涨跌,统计胜率;砍掉没用的信号规则
- **Phase 3(第 2–3 个月)**:视价值决定是否上 X API($200/月);接 Alpaca 模拟盘,
  让 LLM 的"关注建议"变成模拟订单,跑三个月看模拟收益
- **Phase 4(半年后)**:如果模拟盘统计上跑赢基准,再讨论小仓位实盘

## 七、风险与合规声明

- 本系统输出的是**研究线索,不是投资建议**;LLM 会犯错、会过度自信,报告里
  的每个事实引用都应点开原文核实后再行动
- 美股当日涨跌、新闻均为公开信息,系统不涉及任何内幕信息
- 若将来接实盘 API,务必设置单笔金额上限与总仓位上限(代码层面硬性限制)
